# 设计规范（本项目统一遵守）

## 时钟
- 全局唯一主时钟：50 MHz，引脚 CLK = R7。
- 一律使用 clock enable（如 tick_1ms），**禁止**用寄存器生成新时钟再 `always @(posedge clk_1ms)`。
- 不同节拍（1 ms / 1 kHz 控制周期 / 100 ms 遥测）都由 tick 串计数得到，而非新时钟域。

## 复位
- 统一：**同步复位，低有效，信号名 rst_n**。
- 写法：`always @(posedge clk) if (!rst_n) ...`。全工程一致，不混用异步复位。

## 编码风格
- 时序逻辑用 `<=`；组合逻辑用 `always @(*)` 或 `assign`。
- 关键代码注释说明是组合还是时序。
- 模块单一职责，文件名 = 模块名。

## 参数化
- 所有时间参数用 `parameter`，便于 ModelSim 加速：
  - 真实：`MS_DIV = 50000`（50 MHz → 1 kHz）。
  - 仿真：`MS_DIV = 10 / 50` 等。
- 控制/遥测周期同理（如 `CONTROL_DIV`、`TELEM_MS`）。

## 数值与位宽（后续 PID 阶段适用）
- 用定点整数，不用浮点。
- 角度：整数 degree（0~180）；误差/控制/速度：signed。
- PID 必须有：输出限幅、积分限幅、误差限幅。
- 位宽留余量，关注符号位与饱和。

## 开发流程（不得跳步）
写模块 → 写 Testbench → ModelSim 看波形 → 通过 → TD 综合 → 加约束 → 下板 → 实测。

## 禁止事项
- 不猜 ADC / SDRAM / 扩展口引脚；只信板卡原理图与老师约束模板。
- 第一阶段不使用 SDRAM、不依赖 ES8388、不接实体电机。
- 不一次性输出大段未仿真代码。
