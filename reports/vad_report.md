# VAD 阈值实测报告（Phase3a · 2026-09-09 板上 SSCOM）

固件：`top_voice_robot` `CALIB_UART=1`，`audio_calib_rpt` 每 200ms 发
`P<6hex峰值> L<6hex左窗均值> R<6hex右窗均值> V<0/1>`。

## 1. 采集（真实 ES8388 双麦，正常音量，约 30cm）

### 尽量静音（22 行）
- P(帧峰值 max|L|,|R|)：范围 `0x03B9BD`~`0x0837EE`，典型 `0x04xxx`~`0x077xxx`
  → 静音帧峰值 ≤ **0x084000**（噪声底偏高，与 A1 结论一致）。
- L 窗均值 ≈ `0x01D7–0x0415`；R ≈ `0x013A–0x053C`（avg|pcm| ≈ 2^17 量级）。

### 正常说话（36 行，念命令类词）
- P 峰值：常见 `0x0A0000`~`0x180000`，多次 ≥`0x13xxxx`（含 `0x1667AD/0x18BD4F/0x13D4EC`），
  部分为词间停顿的低帧 `0x04E–0x06`。
- L 窗均值最高 `0x091D1E`，R `0x08A9C8`（约为静音均值 4–5×）。

### 拍手/敲击
- P 瞬时冲到 **0x800000**（饱和满刻度）；R/L 窗均值瞬时到 `0x780E96/0x686D8C`。

### 第 2 轮复测（2026-09-09，环境略噪）
- "几乎安静" 背景：P 常见 `0x03–0x0B`，**偶达 0x0D3ACD**（>旧 TH_ON 0x0C0000 → 曾误触发 V=1）。
- 说话（本轮更近/更响）：P 峰值 `0x1C0B00/0x2702CB/0x5B4076/0x654ACA/0x3AE4DA` 等（0x1C–0x65），大量 >0x10。
- 结论：环境背景峰值有"单点尖峰"到 ~0x0D 的特性 → 阈值需高于背景尖峰，同时说话有声帧远高于它。

## 2. 阈值决策（数据驱动，含滞回）

旧默认 `TH_ON=0x040000` **落在静音帧峰值内部** → 静音也 V=1。首轮取 `0x0C0000` 后，
复测背景仍偶达 `0x0D3A`(>0x0C) → 误触发；故再抬高。

| 参数 | 取值 | 依据 |
|---|---|---|
| `VAD_TH_ON` | `0x10_0000` | > 背景尖峰上限 0x0D3A（1.21×）；说话有声帧（0x1C–0x65 或至少 ≥0x10）可靠越过 |
| `VAD_TH_OFF` | `0x0A_0000` | < TH_ON；> 静音典型峰值(0x05–0x0B 常见) → 语音结束帧回落后可走完拖尾 → V 回落 |
| `VAD_HO` | 32 (~170ms) | 词内停顿不切段；命令级单次发声足够 |

调参旋钮：命令不触发→降 TH_ON(如 0x0C0000)；静音/环境误报→升 TH_ON。TH_OFF 始终 < TH_ON 且 > 静音典型峰值。

## 3. 结论
- 静音峰值与说话峰值在约 6–10 dB 分离；瞬时峰值 VAD 可行但裕量有限，本阈值优先"能触发"(reject 误报成本低，因下游还需 owner+cmd 双票)。
- 正式 Demo 语音为"单个命令词"，拖尾 170ms 足够覆盖词内停顿。

文件位置：`rtl/top_voice_robot.v` 顶部 `VAD_TH_ON/VAD_TH_OFF/VAD_HO`。
