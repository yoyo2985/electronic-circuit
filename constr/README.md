# 约束参考（引脚表）

> ⚠️ 安路 TD 的约束文件语法以**老师/板卡原始工程的 .pdc 模板**为准。
> 本文件只提供引脚对照，**禁止**据此自行臆造约束语法。
> 在 TD 的 **IO Constraint 编辑器**里按下表填；或把老师模板拷来改。

## 时钟与复位

| 信号 | 引脚 | 说明 |
|---|---|---|
| clk | R7 | 50 MHz |
| rst_n | 建议接一个拨码开关（如 SW7 = A14） | 拨下=低=复位；不需要消抖 |

## 电平约定

- LED：高 = 亮。
- 数码管字码段：高 = 亮（共阴）。片选：低 = 选中。
- 拨码：拨下（靠边）= 低；拨上（UP）= 高。
